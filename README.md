# Sistema de Fotografía Profesional

## Carlos Daniel Aguilar Alonso

### Actividades del Proyecto

1. Diseñar la interfaz principal del sitio web.
2. Crear el menú de navegación.
3. Implementar la sección de servicios fotográficos.
4. Desarrollar formularios de contacto y cotización.
5. Crear la galería de fotografías.
6. Implementar las tarjetas (Cards) para mostrar paquetes.
7. Agregar enlaces de navegación entre secciones.
8. Diseñar la sección "Sobre Nosotros".
9. Implementar efectos visuales con CSS.
10. Optimizar la interfaz para dispositivos móviles.

### Actividades Concluidas

- Interfaz inicial
- Menú principal
- Descripción del proyecto
- Formularios
- Enlaces de navegación
- Sección de Cards

```javascript
function mostrarBienvenida(nombreCliente) {
```
